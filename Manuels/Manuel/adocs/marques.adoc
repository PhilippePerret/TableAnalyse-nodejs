== Marques ==

Les __marques__ (ou __tags__) sont tous les textes que l'on pose sur la table d'analyse pour analyser la partition. Ce sont les noms des accords, les marques d'harmonie, les marques de modulation, d'emprunt, etc. Voir tous les <<tags-types>>.

NOTE: Pour accélérer la pose des marques, on peut __bloquer__ un type (menu « Marques > Bloquer le type à … > ... ») et poser toutes les marques de ce type d'un coup. Par exemple, on peut poser toutes les marques d'accord d'un coup par ce biais, ce qui accélère considérablement l'analyse. Voir la description dans les <<best-practices, bonnes pratiques>>.

[[tags-chord]]
==== Marque Accord ====

Tous les accords se mettent en notation batave (de A à G). Tous les accords, même les mineurs, se mettent en capital.


[cols="1,2,1", options="header"]
|====
| Nature | Description | exemple
| Accord bémol    | Ajouter un « - » après la note de l'accord    | `B-` pour Si bémol
| Accord dièse    | Ajouter un « + » après la note de l'accord    | `C+` pour Do dièse
| Accord mineur   | Ajouter un « m » après la note de l'accord    |  `B-m` pour Si bémol mineur
| Accord de quinte diminuée | Ajouter « 5- » | `B5-` pour Si quinte diminué (Si Ré Fa)
| Accord (de) septième diminuée | AJouter « 7- » | `B7-` pour Si septième diminuée (Si Ré Fa La bémol)
| Accord demi-diminué | Ajouter « m75- » | `Dm75+` pour D demi-diminué (Ré Fa La bémol Do)
|====

[[tags-segment]]
==== Segment ====

Pour dessiner un segment avec légende ou pas sur ou sous la portée. Pour indiquer des marches harmoniques, par exemple.

Quand on choisit cette marque, un nouveau panneau permet de choisir le type de segment.

[cols="1,3"]
|====
| Plat sur la portée | Pour une indication horizontale AU-DESSUS de la portée.
| Plat sous la portée | Pour une indication horizontale AU-DESSOUS de la portée. 
| Vertical trait gauche | Pour un segment vertical avec le trait À GAUCHE
| Vertical trait droit | Pour un segment vertical avec le trait À DROITE
|====

[[tags-pedal]]
==== Marque de pédale ====

Pour indiquer l'usage d'une pédage, sous le système. Elle correspond au degré de la note (chiffre arabe) dans la tonalité courante.

[[tags-circle]]
==== Marque de cercle ===

* Double-cliqer à l'endroit voulu,
* choisir « Cercle » ou taper la lettre « r ».

Pour définir la taille du cercle, bouger ses bords. La touche MAJ permet d'augmenter la taille en conservant la forme (le cercle, par défaut, ou l'ovale si la dimension horizontale a été modifiéee).

[cols="1,3", options="header"]
|====
2+| Ajout de touches modificatrice
| Majuscule | Conserve la forme (le cercle par exemple) en agrandissant homothétiquement
| Alt     | Maitient le centre du cercle (ou de l'ovale) en place
| Maj+Alt | Accomplit les deux en même temps
|====
