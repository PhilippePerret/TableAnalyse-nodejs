== Introduction ==

**__Table d'analyse__** est une application de bureau qui permet de procéder à des analyses musicales de façon très confortable. Elle a été conçue par Philippe Perret (Prix d'Analyse Musicale à l'unanimité et Prix SACEM pour son travail d'analyse) et codée par Claude (Opus 5.5).

Quand vous êtes confronté(e) à un problème, un bug ou même une envie de fonctionnalité, vous pouvez https://github.com/PhilippePerret/TableAnalyse-nodejs/issues[ouvrir une __issue__^] sur le site Github où l'application est hébergée (« issue » est le terme anglais pour « problème »).
