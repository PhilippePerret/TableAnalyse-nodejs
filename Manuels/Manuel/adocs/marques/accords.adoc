==== Marque de type Accord ====

Une marque accord attend simplement la valeur de l'accord. Cette valeur doit respecter le <<chord-writing, format requis par l'application>>.

On peut ajouter un trait de prolongation simplement en tirant sur le bord droit de la marque. On peut également ajouter ` --` après le nom de l'accord.
